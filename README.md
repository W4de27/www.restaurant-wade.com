# 🍽️ SavorySpot – Modern Restaurant Website

> A responsive and elegant restaurant website featuring menu ordering, table reservations, and a complete dining experience interface.

---

## 🚀 Project Overview

**SavorySpot** is a modern restaurant web application designed to showcase services, menu offerings, and provide users with interactive ordering and reservation features. It delivers a smooth user experience with clean UI and practical functionality.

Built using HTML, CSS, and JavaScript, this project focuses on real-world restaurant operations and user interaction.

---

## ✨ Features

- 🍽️ Showcase of restaurant services & specialties
- 👨‍🍳 Highlight of master chefs and cuisine quality
- 📋 Interactive menu with categories (Burgers, Pizza, Moroccan dishes, Drinks, etc.)
- 🛒 Dynamic order system with live cart (add, update, remove)
- 💰 Real-time total price calculation
- ✅ Order confirmation with unique order number
- 📖 About section (story, mission, feedback)
- 📅 Table reservation system with full details form
- 📩 Reservation confirmation summary card
- 📞 Contact and notification options
